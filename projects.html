Airbnb NYC Price Prediction

Developed an end-to-end machine learning solution using the AB_NYC_2019 dataset to analyze and predict Airbnb listing prices in New York City. The project included data preparation, exploratory analysis, feature engineering, regression modeling, ensemble learning, and log-price modeling.
